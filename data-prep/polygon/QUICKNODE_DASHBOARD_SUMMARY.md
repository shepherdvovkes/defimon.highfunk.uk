# QuickNode Data Dashboard - Summary Report

## 🎯 **Цель проекта**
Создать веб-страницу для отображения данных сети Polygon за последний месяц, извлеченных через QuickNode API.

## 📊 **Извлеченные данные**

### **Статистика сети за последний месяц:**
- **Последний блок**: 75,718,504
- **Блоков за месяц**: 5,184,001
- **Текущая цена газа**: 25.99 Gwei
- **Период анализа**: 30 дней

### **Типы данных, которые мы можем извлечь:**

#### **1. Блоки (Blocks)**
- Номер блока и хеш
- Временная метка
- Использованный газ
- Количество транзакций
- Минер блока
- Сложность и другие параметры

#### **2. Транзакции (Transactions)**
- Хеш транзакции
- Адреса отправителя и получателя
- Сумма перевода
- Цена газа
- Входные данные (input data)
- Тип транзакции

#### **3. Квитанции (Receipts)**
- Статус транзакции (успех/неудача)
- Использованный газ
- Логи событий
- Адрес контракта (если есть)

#### **4. Логи событий (Event Logs)**
- События смарт-контрактов
- Топики событий
- Данные событий

## 🛠️ **Созданные инструменты**

### **1. QuickNode Data Explorer** (`quicknode_data_explorer.py`)
- Извлекает данные за последний месяц
- Получает статистику сети
- Собирает образцы блоков и транзакций
- Сохраняет анализ в JSON формате

### **2. Data Dashboard Creator** (`create_data_dashboard.py`)
- Создает современную веб-страницу
- Интерактивные графики и диаграммы
- Таблицы с образцами данных
- Адаптивный дизайн

### **3. Dashboard Server** (`start_quicknode_dashboard.sh`)
- Автоматически запускает веб-сервер
- Открывает браузер
- Управляет процессом

## 🚀 **Как использовать**

### **Быстрый старт:**
```bash
# 1. Извлечь данные
python3 quicknode_data_explorer.py

# 2. Создать дашборд
python3 create_data_dashboard.py

# 3. Запустить сервер и открыть браузер
./start_quicknode_dashboard.sh
```

### **Ручной запуск:**
```bash
# Запустить веб-сервер
python3 -m http.server 8000

# Открыть в браузере
open http://localhost:8000/quicknode_dashboard.html
```

## 📋 **Технические детали**

### **API Endpoints использованные:**
- `eth_blockNumber` - получение последнего блока
- `eth_getBlockByNumber` - получение блока по номеру
- `eth_getTransactionReceipt` - получение квитанции транзакции
- `eth_gasPrice` - получение текущей цены газа
- `eth_getLogs` - получение логов событий

### **Технологии веб-страницы:**
- **HTML5** - структура страницы
- **Tailwind CSS** - стилизация и адаптивность
- **Chart.js** - интерактивные графики
- **Font Awesome** - иконки
- **JavaScript** - интерактивность

### **Формат данных:**
- **JSON** - структурированные данные
- **Hex** - шестнадцатеричные значения
- **Wei/Gwei** - единицы измерения газа
- **Timestamp** - временные метки

## 🔄 **Обновление данных**

### **Для обновления данных:**
```bash
# 1. Извлечь новые данные
python3 quicknode_data_explorer.py

# 2. Пересоздать дашборд
python3 create_data_dashboard.py

# 3. Обновить страницу в браузере
```

### **Автоматическое обновление:**
Можно настроить cron job для автоматического обновления данных:
```bash
# Каждый час
0 * * * * cd /path/to/polygon && python3 quicknode_data_explorer.py && python3 create_data_dashboard.py
```
