# Polygon Monthly Data Collection Guide

## 🎯 **Цель**
Перезагрузить данные за последний месяц по сети Polygon, используя QuickNode API и сохранить их в PostgreSQL базу данных Google Cloud.

## 📊 **Система сбора данных**

### **Компоненты:**
1. **QuickNode API** - источник данных
2. **PostgreSQL Google Cloud** - хранилище данных
3. **Cloud SQL Proxy** - безопасное подключение
4. **Асинхронные скрипты** - эффективный сбор данных

### **Созданные скрипты:**

#### **1. `collect_monthly_data.py`** - Основной сборщик данных
- Собирает данные за последний месяц (5,184,000 блоков)
- Обрабатывает блоки батчами по 100 штук
- Собирает транзакции и квитанции
- Сохраняет в PostgreSQL в реальном времени

#### **2. `test_data_collection.py`** - Тестовый сборщик
- Собирает данные с последних 10 блоков
- Ограничивает транзакции до 10 на блок
- Для тестирования системы

#### **3. `run_monthly_collection.sh`** - Запуск полного сбора
- Проверяет подключение к базе данных
- Показывает текущую статистику
- Запускает полный сбор с подтверждением

#### **4. `run_test_collection.sh`** - Запуск теста
- Автоматически запускает тестовый сбор
- Без подтверждения пользователя

## 🗄️ **База данных PostgreSQL**

### **Таблицы:**
1. **`polygon_data.blocks`** - блоки сети
2. **`polygon_data.transactions`** - транзакции
3. **`polygon_data.receipts`** - квитанции транзакций

### **Подключение:**
- **Хост**: localhost:5432 (через Cloud SQL Proxy)
- **База данных**: `defi_analytics`
- **Пользователь**: `defimon_user`
- **Схема**: `polygon_data`

### **1. Быстрый тест системы:**


### **2. Полный сбор данных за месяц:**


## 🔍 **Проверка данных**

### **Подключение к базе:**
```bash
psql -h localhost -U defimon_user -d defi_analytics
```

### **Полезные запросы:**
```sql
-- Общая статистика
SELECT 
    'blocks' as table_name, COUNT(*) as count FROM polygon_data.blocks
UNION ALL
SELECT 
    'transactions' as table_name, COUNT(*) as count FROM polygon_data.transactions
UNION ALL
SELECT 
    'receipts' as table_name, COUNT(*) as count FROM polygon_data.receipts;

-- Диапазон блоков
SELECT MIN(block_number), MAX(block_number) FROM polygon_data.blocks;

-- Процент успешных транзакций
SELECT 
    status, 
    COUNT(*) as count, 
    ROUND(COUNT(*) * 100.0 / SUM(COUNT(*)) OVER (), 1) as percentage 
FROM polygon_data.receipts 
GROUP BY status;
```

## 🛠️ **Устранение неполадок**

### **Проблема: Cloud SQL Proxy не запущен**
```bash
./cloud_sql_proxy -instances=defimon-ethereum-node:us-central1:defimon-postgres-instance=tcp:5432 &
```

### **Проблема: Ошибка подключения к базе**
```bash
# Проверить статус
lsof -i :5432

# Перезапустить прокси
pkill -f cloud_sql_proxy
./cloud_sql_proxy -instances=defimon-ethereum-node:us-central1:defimon-postgres-instance=tcp:5432 &
```

### **Проблема: Ошибка API**
- Проверить QuickNode endpoint
- Проверить лимиты API
- Увеличить задержку между запросами
